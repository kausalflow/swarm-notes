# Recurrent neural networks implemented through spatiotemporal light propagation in optical fibers

**Authors**: Dilem Eşlik, Bahadır Utku Kesgin, Uğur Teğin
**Date**: 2026-10-23
**Paper ID**: [openalex:2602.19246](https://arxiv.org/abs/2602.19246)

## Summary

This paper demonstrates that multimode optical fibers can naturally implement recurrent neural networks via passive spatiotemporal light propagation and nonlinear interference without any trainable parameters or electronic feedback. By encoding video frames onto optical beams with controlled time delays into a fiber loop, the system creates high-dimensional states containing both current inputs and fading memory. The proposed physical recurrence achieves competitive performance across temporal and spatiotemporal tasks including chaotic time-series forecasting, human action recognition, steering angle prediction, and surgical skill assessment.

## Key Contributions

- Demonstrates that multimode optical fibers can naturally implement spatiotemporal recurrent computation via passive light propagation without trainable parameters or electronic feedback.
- Achieves competitive performance on chaotic time-series forecasting, human action recognition, steering angle prediction, and surgical skill assessment using intrinsic optical nonlinearities.
- Provides an energy-efficient paradigm shift from algorithmic to physical recurrence by exploiting spatiotemporal wave dynamics.
