# A Hybrid Anomaly Detection Method for Multivariate Time Series

**Authors**: Ali Babalhavaeji, Hui Song, Mahdi Jalili
**Date**: 2026-11-01
**Paper ID**: [openalex:2611.01661](https://arxiv.org/abs/2611.01661)

## Summary

This paper proposes a hybrid deep learning-based anomaly detection method for multivariate time series to capture both spatial and temporal dependencies in complex monitoring systems. The method integrates a variational autoencoder with 2D convolutional networks for feature extraction, alongside a prediction-based architecture combining 2D convolutions and gated recurrent units (GRUs). Evaluations on public benchmarks demonstrate competitive performance against state-of-the-art approaches.

## Key Contributions

- Proposes a hybrid deep learning-based anomaly detection method for multivariate time series that integrates both temporal and spatial information.
- Combines the feature extraction capabilities of 2D convolutional networks within a variational autoencoder with a prediction-based deep neural network composed of 2D convolutions and gated recurrent units (GRUs).
- Demonstrates effectiveness against state-of-the-art methods on public multivariate time series datasets.
