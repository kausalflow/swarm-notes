# Ensemble quantile-based deep learning framework for streamflow and flood prediction in Australian catchments

**Authors**: Rohitash Chandra, Arpit Kapoor, Siddharth Khedkar, Jim Ng, W. Vervoort
**Date**: 2026-10-25
**Paper ID**: [openalex:2407.15882](https://arxiv.org/abs/2407.15882)

## Summary

This paper presents an ensemble quantile-based deep learning framework for streamflow forecasting and flood prediction in Australian catchments, addressing challenges such as model calibration and missing data during extreme flooding events. By utilizing quantile regression for uncertainty projections and combining historical streamflow data with flood frequency analysis, the proposed framework accurately estimates flood probabilities and captures historical flood events. Evaluations using the CAMELS dataset demonstrate the framework's efficacy across diverse catchment properties, highlighting its potential for early warning systems.

## Key Contributions

- Proposes an ensemble quantile-based deep learning framework for large-scale streamflow and flood prediction using quantile regression.
- Evaluates univariate and multivariate deep learning models with various catchment strategies on the CAMELS dataset across Australian catchments.
- Combines streamflow forecasts with flood frequency analysis to estimate flood probabilities and accurately capture historical flooding events.
