# Testing for functional white noise in high dimensions

**Authors**: Jinyuan Chang, Qi Jiang, Xinghao Qiao, Lin Yang
**Date**: 2026-07-23
**Paper ID**: [openalex:2607.20877](https://arxiv.org/abs/2607.20877)

## Summary

This paper develops a general error-contamination framework for white noise testing in high-dimensional functional time series. By introducing a supremum-type test statistic based on cross-autocovariance functions and a parametric bootstrap procedure, the method handles both discretely observed functional time series and residual-based goodness-of-fit tests for functional factor models. Theoretical guarantees including size control and asymptotic power are established via new Gaussian approximation results.

## Key Contributions

- Develops a general error-contamination framework for testing white noise in high-dimensional functional time series.
- Proposes a supremum-type test statistic based on cross-autocovariance functions along with a parametric bootstrap procedure for null distribution approximation.
- Establishes Gaussian approximation and asymptotic power guarantees under high-level conditions, applied to discretely observed functional time series and residual-based goodness-of-fit tests for functional factor models.
