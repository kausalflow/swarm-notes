# Model Specification Test for Stationary Functional Time Series

**Authors**: Yan Cui, Holger Dette, Zhou Zhou
**Date**: 2026-09-23
**Paper ID**: [openalex:2609.27182](https://arxiv.org/abs/2609.27182)

## Summary

This paper introduces a general framework for model specification testing in stationary functional time series via an increasing-dimension autoregressive approximation. By measuring deviations from structural restrictions on coefficient kernels using weighted L2-distances and multiplier bootstrap critical values, the approach tackles functional autoregressive order testing, FARMA specification testing, and separability testing of coefficient kernels. Theoretical results prove asymptotic validity and consistency under uniform convergence over weight classes.

## Key Contributions

- Developed a general framework for model specification testing in stationary functional time series using an autoregressive approximation with increasing dimension and order.
- Formulated test statistics based on weighted L2-distances to capture structural restrictions for three specific problems: testing functional autoregressive model order, testing FARMA specifications, and testing separability of autoregressive coefficient kernels.
- Established a quantitative bootstrap approximation uniform over weight functions and proved asymptotic validity and consistency using a multiplier bootstrap for critical values.
