# The Last Remote Sensing Model Built by Humans? Casting Any Earth Observation Task as Recursive Self-Improvement

**Authors**: Sijie Zhao, Zeqi Zhou, Heli Qi, Xuanchao Fu, Zhuo Zheng, Junshi Xia, Junjue Wang, Weihao Xuan, Naoto Yokoya
**Date**: 2026-10-13
**Paper ID**: [openalex:2610.18845](https://arxiv.org/abs/2610.18845)

## Summary

This paper introduces a paradigm shift in Earth observation (EO) modeling by replacing manual model construction with a general-purpose coding agent that recursively improves models through verifiable harnesses and verifiers. By framing diverse EO tasks—such as few-shot learning and domain adaptation—around task-specific harnesses and verifiers, agent-built models outperform existing state-of-the-art baselines across optical, SAR, and multispectral time-series benchmarks while utilizing as little as 1% of training labels.

## Key Contributions

- Demonstrates that any Earth observation task can be cast as a harness and a verifier for recursive self-improvement by a coding agent.
- Unified disparate remote sensing settings (few-shot learning, domain adaptation) into distinct choices of harness and verifier.
- Surpasses state-of-the-art performance across four Earth observation benchmarks spanning optical, SAR, and multispectral time-series imagery while retaining high accuracy with only 1% of training labels.
