# Physics-informed deep learning links geodetic data and fault friction

**Authors**: Rikuto Fukushima, Masayuki Kano, Kazuro Hirahara, Makiko Ohtani
**Date**: 2026-10-12
**Paper ID**: [openalex:2601.20136](https://arxiv.org/abs/2601.20136)

## Summary

This paper introduces a Physics-Informed Neural Network (PINN) approach to invert geodetic observations for spatially variable fault frictional properties, addressing high-dimensional optimization challenges in fault mechanics. Applied to the 2010 Bungo Slow Slip Event (SSE) in Japan, the model successfully uncovers localized frictional heterogeneity driving nucleation and propagation, while accurately forecasting future slip evolution across multiple cycles.

## Key Contributions

- Applied Physics-Informed Neural Networks (PINNs) to link fault frictional heterogeneity directly with geodetic observations, overcoming high-dimensional optimization bottlenecks.
- Targeted the 2010 Bungo Slow Slip Event (SSE) in southwest Japan, recovering heterogeneous friction distributions that successfully reproduce observed spatio-temporal surface displacement patterns.
- Demonstrated physics-based forecasting of future fault slip evolution by assimilating observations spanning multiple SSE cycles.
