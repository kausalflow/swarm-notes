# Forecasting Voltage Time Series under Anomalies Using a WGAN Model With Lipschitz Control and Progressive Kernel Critic Strategy

**Authors**: Najmieh Sadat Safarabadi
**Date**: 2026-10-30
**Paper ID**: [openalex:2610.23394](https://arxiv.org/abs/2610.23394)

## Summary

This paper introduces a Wasserstein GAN model featuring a progressive Lipschitz penalty and an adaptive kernel critic (WGAN-CLP) to tackle high-dimensional recursive forecasting of voltage time series under anomalies. By dynamically adapting its kernel to each incoming window, the model successfully captures complex long-term temporal dynamics and streaming alterations. Evaluations using power ratios, correlation coefficient, and relative root mean squared error demonstrate that the proposed framework outperforms existing benchmark methods in accuracy and robustness.

## Key Contributions

- Proposes a Wasserstein GAN framework equipped with a progressive Lipschitz penalty and adaptive kernel (WGAN-CLP) for robust high-dimensional recursive voltage time-series forecasting under anomalies.
- Extends the WGAN-LP formulation with an adaptive kernel critic model capable of dynamically adapting to streaming data windows.
- Demonstrates superior performance over benchmark methods using power ratios, correlation coefficient (CC), and relative root mean squared error (RRMSE) on voltage and energy time-series datasets.
