# Practical Quantum Topological Data Analysis with Applications to High-Dimensional Feature Extraction and Time Series Analysis

**Authors**: Jason Iaconis, Sayonee Ray, Samwel Sekwao, Claudio Girotto, Martin Roetteler
**Date**: 2026-07-29
**Paper ID**: [openalex:2607.27206](https://arxiv.org/abs/2607.27206)

## Summary

This paper presents a practical quantum topological data analysis (TDA) framework for high-dimensional feature extraction and time-series analysis by framing quantum TDA as a downstream feature-extraction method. Instead of requiring exact Betti number estimation, the approach extracts low-order spectral information from the combinatorial Laplacian as a proxy for topology, supported by a moment-based quantum algorithm. Evaluations across functional MRI classification and financial time-series forecasting, alongside experimental hardware demonstrations, establish the practicality of quantum-assisted TDA.

## Key Contributions

- Frames quantum topological data analysis as a downstream feature-extraction method using low-order spectral information from the combinatorial Laplacian.
- Demonstrates improved predictive performance on functional MRI neurodegenerative classification and financial market instability time-series applications.
- Develops a moment-based quantum algorithm showing low-order moments correlate strongly with high-dimensional Betti information.
- Provides circuit constructions, resource estimates, and experimental results from a Barium development system comparing Laplacian-derived observables with exact Betti numbers.
