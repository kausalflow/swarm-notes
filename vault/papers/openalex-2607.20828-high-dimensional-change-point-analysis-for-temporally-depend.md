# High-Dimensional Change Point Analysis for Temporally Dependent Data

**Authors**: Xiaoyi Wang, Le Zhou, Ji‐Xuan Liu, Long Feng
**Date**: 2026-07-23
**Paper ID**: [openalex:2607.20828](https://arxiv.org/abs/2607.20828)

## Summary

This paper develops adaptive procedures for detecting and locating mean changes in high-dimensional time series by combining quadratic CUSUM statistics for dense changes and coordinatewise maximum statistics for sparse changes. Under general non-Gaussian vector dependence, the authors establish the limiting distributions, validate centering and scaling estimators, and prove asymptotic independence between matched statistics to justify Cauchy combination tests. Furthermore, they establish single-change localization and consistent multiple-change recovery using wild binary segmentation.

## Key Contributions

- Developed adaptive change point analysis procedures for high-dimensional time series targeting both dense and sparse mean changes using quadratic CUSUM and coordinatewise maximum statistics.
- Established limiting distributions, centering/scaling estimators, and asymptotic independence between matched quadratic and maximum statistics under general non-Gaussian vector dependence, justifying Cauchy combination tests.
- Established single-change localization and consistent multiple-change recovery guarantees using wild binary segmentation.
