# Versatile Quantum Machine Learning with an Ultra-low Power Photonic Quantum Reservoir Computer

**Authors**: Wei Wang, Zan Tang, Menglong Fang, Daiqin Su, Mile Gu, Jayne Thompson, Lip Ket Chin, Hong Cai, L. C. Kwek, Ai-Qun 刘爱群 Liu
**Date**: 2026-09-21
**Paper ID**: [openalex:2609.24381](https://arxiv.org/abs/2609.24381)

## Summary

This paper demonstrates an integrated photonic quantum reservoir computer that achieves nonlinear mapping, fading memory, and task versatility without active tuning of the reservoir core. By combining quantum-state encoding, multimode interferometric mixing, and photon-statistical readout, the architecture supports static classification, dynamic prediction, and autonomous forecasting. Crucially, competitive performance is retained in a zero-bias state with unpowered phase shifters, achieving zero computational power consumption through passive operation.

## Key Contributions

- Demonstrated an integrated photonic quantum reservoir computer supporting nonlinear mapping, fading memory, and task versatility without active tuning of the reservoir core.
- Achieved competitive performance across static classification, dynamic prediction, and stable autonomous forecasting.
- Eliminated active control power via zero-bias passive operation, where unpowered on-chip phase shifters reduce computational power consumption to zero.
