# An Efficient Machine Learning Approach for Degradation Forecasting in AEM Water Electrolysis

**Authors**: Marco Veneriano, Ani Gjergji, Sebastiano Bellani, Andrea Riva, Vito Paolo Pastore, Matteo Santacesaria
**Date**: 2026-09-29
**Paper ID**: [openalex:2609.37941](https://arxiv.org/abs/2609.37941)

## Summary

This paper presents a data-driven approach for forecasting degradation curves in Anion Exchange Membrane water electrolyzers (AEMWE) using a novel experimental dataset spanning multiple heterogeneous industrial campaigns. The authors evaluate various machine learning models, ranging from simple linear baselines to LSTMs and CNNs, within a rigorous evaluation framework. The results demonstrate the efficacy of machine learning for medium-term degradation prediction in green hydrogen production technologies.

## Key Contributions

- Evaluated a range of machine learning models from linear baselines to LSTMs and CNNs for medium-term cell voltage degradation forecasting in Anion Exchange Membrane water electrolyzers (AEMWE).
- Utilized a novel dataset of single-cell AEM water electrolyzers operated under constant current load across multiple heterogeneous experimental campaigns.
- Designed a rigorous training and evaluation framework specifically tailored for heterogeneous industrial degradation data.
