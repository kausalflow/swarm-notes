# Predicting Subsurface Abnormalities Growth using Physics-Informed Neural Networks

**Authors**: Mehrdad Shafiei Dizaji, Hoda Azari
**Date**: 2026-09-01
**Paper ID**: [openalex:2609.01417](https://arxiv.org/abs/2609.01417)

## Summary

This paper presents a Physics-Informed Neural Network (PINN) framework for predicting subsurface abnormality growth using Ground-Penetrating Radar (GPR) data, akin to tumor prediction in medical imaging. The architecture integrates CNNs, ConvLSTM, and self-adaptive spatial and temporal feature attention mechanisms (SFCA and TFFA) with the physical laws of electromagnetic wave propagation. By embedding physical principles directly into the network, the model improves the precision of non-destructive evaluation (NDE) for civil infrastructure and bridge deck monitoring.

## Key Contributions

- Introduces a specialized Physics-Informed Neural Network (PINN) framework for predicting subsurface abnormalities using Ground-Penetrating Radar (GPR) data.
- Integrates electromagnetic wave propagation physics directly into a deep learning architecture composed of CNN, convolutional LSTM (ConvLSTM), and spatial/temporal feature attention mechanisms (SFCA and TFFA).
- Demonstrates enhanced accuracy in forecasting structural deterioration and bridge deck conditions for Non-Destructive Evaluation (NDE).
