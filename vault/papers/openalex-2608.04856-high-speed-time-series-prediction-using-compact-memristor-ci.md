# High-speed time-series prediction using compact memristor circuits with adjustable dynamics

**Authors**: Dániel Molnár, János Volk, Tímea Nóra Török, Z. Balogh, Nadia Jimenez Olalla, Miklós Csontos, Juerg Leuthold, András Halbritter
**Date**: 2026-08-05
**Paper ID**: [openalex:2608.04856](https://arxiv.org/abs/2608.04856)

## Summary

This paper introduces a compact time-series prediction framework using Ta2O5 nonvolatile memristors as dynamic reservoir computing layers. By exploiting strongly voltage-dependent switching speeds to tailor programming and forgetting dynamics, the system achieves high prediction accuracy with as few as two to six memristive channels. Furthermore, the approach allows the operating frequency to be tuned from the kHz to the MHz range by adjusting input voltage levels, demonstrating potential for high-speed temporal signal analysis approaching telecommunication data rates.

## Key Contributions

- Demonstrates the use of Ta2O5 nonvolatile memristors as compact dynamic reservoir computing layers for high-speed time-series prediction.
- Leverages strongly voltage-dependent switching speed to configure tailorable programming and forgetting times.
- Achieves high prediction accuracy using a minimal number of memristive input channels (six with fixed forgetting times, or only two when optimizing forgetting times).
- Enables operating frequency tunability from kHz to MHz ranges while maintaining prediction accuracy, approaching telecommunication data rates.
