# A Multi-Modal AI Framework for Real-Time Queue Prediction, Management and Optimisation in Intelligent Border Control Systems

**Authors**: Varvara Mama, Eleni Veroni, Nikolaos Kapsalis, Christos D. Nikolopoulos, Anargyros T. Baklezos
**Date**: 2026-08-27
**Paper ID**: [openalex:2608.27010](https://arxiv.org/abs/2608.27010)

## Summary

This paper proposes a multi-modal AI framework for real-time queue prediction, management, and resource optimization in intelligent border control systems. The approach integrates heterogeneous traffic data into a unified representation, utilizing Long Short-Term Memory (LSTM) networks for forecasting and Model Predictive Control (MPC) for actionable policy generation. Evaluations on synthetic traffic data demonstrate significant improvements, reducing queue prediction error by up to 35% and average waiting time by 30% compared to ARIMA and rule-based methods.

## Key Contributions

- Proposes a multi-modal AI framework integrating heterogeneous data sources for real-time queue prediction and resource optimization in intelligent border control systems.
- Employs Long Short-Term Memory (LSTM) networks combined with Model Predictive Control (MPC) and scheduling optimization to derive actionable control policies.
- Demonstrates up to a 35% reduction in queue prediction error and a 30% reduction in average waiting time compared to ARIMA and rule-based baselines.

## Limitations

Evaluated using synthetic data simulating realistic traffic; real-world deployment validation remains future work.
