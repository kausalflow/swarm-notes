# Temporal information processing on a 4,500-qubit quantum annealer

**Authors**: Antonio Sannia, Roberto Menta, Pratik Sathe, Dario De Santis, Vittorio Giovannetti, Luis Pedro García-Pintos, Davide Venturelli, Gian Luca Giorgi, Roberta Zambrini, Francesco Caravelli
**Date**: 2026-09-16
**Paper ID**: [openalex:2609.19308](https://arxiv.org/abs/2609.19308)

## Summary

This paper presents a large-scale quantum machine learning experiment utilizing up to 4,500 qubits on a superconducting quantum annealer for temporal data processing. Following the quantum reservoir computing paradigm, the authors employ the untrained native many-body dynamics generated by reverse annealing, avoiding expensive parameter optimization training loops. They prove that many-body interactions are essential for memory retention and successfully evaluate the system on memory benchmarks and chaotic time series forecasting.

## Key Contributions

- Demonstrates a quantum machine learning model processing temporal data using up to 4,500 qubits on a programmable superconducting quantum annealer, representing the largest QML experiment to date.
- Applies the quantum reservoir computing paradigm by leveraging untrained native many-body dynamics generated by reverse annealing without expensive parameter optimization training loops.
- Proves analytically and experimentally that many-body interactions produced during annealing are indispensable for memory retention, while non-interacting reservoirs fail.
- Evaluates the model on standard memory benchmarks and successfully forecasts chaotic time series, establishing quantum annealers as a scalable platform for temporal information processing.
