# A Temporal Multiplex Graph Neural Network for Systemic Risk Transmission in Global Banking

**Authors**: Nneka Umeorah, Tolulope Fadina
**Date**: 2026-08-27
**Paper ID**: [openalex:2608.27295](https://arxiv.org/abs/2608.27295)

## Summary

This paper introduces a Temporal Heterogeneous Multiplex Graph Neural Network to model systemic risk transmission and contagion channels across global banks using quarterly fundamental, CDS, and macroeconomic data. The framework combines graph convolutions, recurrent GRU dynamics, and a learnable fusion gate to dynamically weight alternative contagion pathways. Empirical evaluations demonstrate that the approach outperforms traditional econometric, machine learning, and graph-based benchmarks in predicting short-term changes in CDS spreads, while also enabling interpretable stress testing, spillover analysis, and edge perturbation studies.

## Key Contributions

- Developed a Temporal Heterogeneous Multiplex Graph Neural Network framework for systemic risk transmission and contagion channel identification in global banking.
- Integrated graph convolutional layers with recurrent GRU dynamics and a learnable fusion gate to capture time-varying reliance on alternative contagion channels.
- Demonstrated superior forecasting performance over conventional econometric, machine learning, and graph-based benchmarks for short-term changes in CDS spreads.
- Provided an interpretable framework for bank-level systemic importance via stress testing, country-level spillover assessment, and pathway uncovering through edge perturbation analysis.
