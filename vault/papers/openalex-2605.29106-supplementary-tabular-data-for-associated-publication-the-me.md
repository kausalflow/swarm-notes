# Supplementary tabular data for associated publication: "The MeerKAT Thousand-Pulsar Polarization Array I: Properties of the Polarization and Rotation Measure Time Series Data"

**Authors**: Michael Sarkis, Zi-Yan Yuwen, Yin-Zhe Ma, Tao Liu, Jng Ren, Patrick Weltevrede, Xiao Xue
**Date**: 2026-08-14
**Paper ID**: [openalex:2605.29106](https://arxiv.org/abs/2605.29106)

## Summary

This paper presents supplementary tabular data containing basic metadata and Markov Chain Monte Carlo (MCMC) posterior information regarding the noise properties of pulsar time series data. The dataset supports the associated publication analyzing the polarization and rotation measure time series from the MeerKAT Thousand-Pulsar Polarization Array.

## Key Contributions

- Provided supplementary tabular metadata and MCMC posterior information on noise properties for the pulsar population analyzed in the MeerKAT Thousand-Pulsar Polarization Array I study.
- Released data tables detailing polarization and rotation measure time series properties for an extensive pulsar population.
