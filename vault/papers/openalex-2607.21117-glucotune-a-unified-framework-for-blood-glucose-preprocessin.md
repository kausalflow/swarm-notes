# GlucoTune: A Unified Framework for Blood Glucose Preprocessing, Forecasting, and Benchmarking in Diabetes

**Authors**: Davide Marelli, Giorgia Rigamonti, Mirko Paolo Barbato, Paolo Napoletano
**Date**: 2026-07-23
**Paper ID**: [openalex:2607.21117](https://arxiv.org/abs/2607.21117)

## Summary

GlucoTune is a comprehensive framework designed to standardize the end-to-end experimental workflow for blood glucose time-series forecasting in diabetes management, addressing reproducibility challenges caused by data preprocessing variability and privacy constraints. The framework offers portable YAML-based preprocessing pipelines, standardized dataset wrappers, a collection of state-of-the-art prediction models, and a benchmarking leaderboard for systematic evaluation.

## Key Contributions

- Introduces GlucoTune, a unified and extensible framework for blood glucose time-series preprocessing, forecasting, and benchmarking in diabetes management.
- Achieves reproducible preprocessing through configurable pipelines defined in portable YAML configuration files, resolving privacy and data-sharing constraints.
- Provides a benchmarking leaderboard and standardized wrappers for integrating public datasets and state-of-the-art forecasting methods.
