# Crossing margins: Intersectional users’ ethical concerns about software

**Authors**: Lauren Olson, Tom P. Humbert, Ricarda Anna-Lena Fischer, Bob Westerveld, Florian Kunneman, Emitzá Guzmán
**Date**: 2026-08-24
**Paper ID**: [openalex:2410.08090](https://arxiv.org/abs/2410.08090)

## Summary

This paper investigates the ethical concerns of intersectional communities regarding software applications by analyzing over 36,000 posts from intersectional subreddits using large language models. The authors apply regression models with counterfactual analysis and time-series methods to understand how identity dimensions shape ethical concern expression and how these concerns evolve over real-world events. Finally, they demonstrate a feedback-driven framework for prioritizing software issues warranting developer attention.

## Key Contributions

- Collected 36,777 posts from over 700 intersectional subreddits discussing software applications to analyze ethical concerns.
- Utilized large language models to identify software-related ethical concerns and applied regression models with counterfactual analysis to examine identity dimensions shaping concern expression.
- Conducted a time-series analysis to examine how concern expression varies over time in relation to real-world events.
- Demonstrated a case study in the social media domain prioritizing ethical concerns validated against survey-derived ground truth.
