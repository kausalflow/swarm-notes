# Dynamic latent class structural equation modeling: A hands-on tutorial for modeling intensive longitudinal data.

**Authors**: Roberto Faleh, Sofia Morelli, Vivato Andriamiarana, Zachary Joseph Roman, Christoph Flückiger, Holger Brandt
**Date**: 2026-08-10
**Paper ID**: [openalex:2508.12983](https://arxiv.org/abs/2508.12983)

## Summary

This tutorial paper presents a comprehensive, step-by-step guideline for implementing Dynamic Latent Class Structural Equation Models (DLCSEM) using the Bayesian software JAGS for intensive longitudinal data. The authors build up from Confirmatory Factor Analysis and Time Series models to Multilevel Models, Dynamic Structural Equation Models (DSEM), and Hidden Markov Switching Models (HMSM), culminating in their integration. A practical empirical example from clinical psychology evaluating generalized anxiety treatment and therapeutic alliance is used throughout to demonstrate model specification, JAGS implementation, and result interpretation.

## Key Contributions

- Provides a step-by-step hands-on tutorial and implementation guide for Dynamic Latent Class Structural Equation Models (DLCSEM) using the Bayesian software JAGS.
- Demonstrates the integration of Hidden Markov Switching Models (HMSM) with Dynamic Structural Equation Models (DSEM) to form DLCSEMs.
- Illustrates the modeling workflow using an intensive longitudinal dataset from clinical psychology involving generalized anxiety treatment and working alliance scales.

## Limitations

The work is primarily tutorial-driven and methodological in pedagogical scope rather than presenting a novel machine learning architecture or breakthrough performance claim.
