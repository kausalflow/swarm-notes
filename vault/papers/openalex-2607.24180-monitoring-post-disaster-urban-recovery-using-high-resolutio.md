# Monitoring Post-Disaster Urban Recovery Using High-Resolution SAR Time Series and Unsupervised Learning: Evidence from the 2023 Türkiye-Syria Earthquake

**Authors**: Luigi Russo, Deodato Tapete, Silvia Liberata Ullo, Paolo Gamba
**Date**: 2026-07-27
**Paper ID**: [openalex:2607.24180](https://arxiv.org/abs/2607.24180)

## Summary

This paper proposes an unsupervised framework for monitoring post-disaster urban recovery using multi-temporal synthetic aperture radar (SAR) observations and deep-learning anomaly detection. Applied to cities affected by the 2023 Türkiye-Syria earthquakes using COSMO-SkyMed time series, the approach identifies persistent temporal anomalies associated with reconstruction activities without requiring labeled ground-truth data. Comparing SAR-derived structural changes with SDGSAT-1 nighttime-light indicators reveals complementary insights into rebuilding dynamics and restoration of socioeconomic activity.

## Key Contributions

- Proposes an unsupervised framework using multi-temporal SAR time series (COSMO-SkyMed) and deep-learning anomaly detection for post-disaster urban recovery monitoring.
- Applies the framework to four cities affected by the 2023 Türkiye-Syria earthquakes to generate spatially explicit recovery maps without requiring labeled ground-truth data.
- Demonstrates the complementary nature of SAR-based structural recovery mapping and SDGSAT-1 nighttime-light indicators, showing that SAR anomalies can capture reconstruction at earlier stages in built environments.
