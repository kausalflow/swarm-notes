# CheMLFlow: An Open-Source Platform for Cheminformatics and Materials Informatics Applications

**Authors**: B.L. Smith, Susana Lopez-Moreno, Eric Dolores-Cuenca, Sangil Kim, Jose L. Mendoza-Cortes, Nijamudheen Abdulrahiman
**Date**: 2026-08-05
**Paper ID**: [openalex:2608.04942](https://arxiv.org/abs/2608.04942)

## Summary

CheMLFlow is an open-source, configuration-driven platform designed to streamline end-to-end, high-throughput, and agentic machine learning workflows in cheminformatics, materials informatics, and general scientific applications. By providing modular components, pluggable representations, standardized artifacts, and agent-friendly structured outputs, the framework eliminates orchestration overhead while matching state-of-the-art performance across quantum mechanical, physicochemical, bioactivity, and time-series tasks.

## Key Contributions

- Introduces CheMLFlow, an open-source platform for building modular, end-to-end, high-throughput, and agentic scientific workflows.
- Addresses the orchestration bottleneck in scientific machine learning by integrating data curation, representation, model training, validation, screening, and reporting into reproducible pipelines.
- Demonstrates literature-level performance across quantum mechanical, physicochemical, and bioactivity property prediction tasks, as well as time-series datasets.
