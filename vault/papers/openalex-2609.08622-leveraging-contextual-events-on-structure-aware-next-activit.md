# Leveraging contextual events on structure-aware next activity prediction

**Authors**: Alessandro Mele, Claudia Diamantini, Domenico Potena
**Date**: 2026-09-08
**Paper ID**: [openalex:2609.08622](https://arxiv.org/abs/2609.08622)

## Summary

This paper investigates next activity prediction in predictive process monitoring by leveraging contextual events and environmental conditions. The authors propose an approach based on Instance Graphs combined with novel encoding strategies to explicitly capture contextual process instances. Evaluated across multiple real-world event logs using Graph Neural Networks, the proposed method demonstrates that incorporating contextual information significantly enhances prediction performance.

## Key Contributions

- Introduces a structure-aware approach based on Instance Graphs for next activity prediction in predictive process monitoring.
- Proposes several encoding strategies to explicitly incorporate contextual information and environmental conditions from event log attributes.
- Evaluates the prefix-Instance Graphs using a Graph Neural Network on multiple real-world event logs, demonstrating performance improvements.
