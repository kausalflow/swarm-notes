# Skillful subseasonal-to-seasonal ensemble forecasting with a multi-sphere coupled probabilistic model

**Authors**: Bin Mu, Yuxuan Chen, Shijin Yuan, Bo Qin, Hao Guo
**Date**: 2026-10-30
**Paper ID**: [openalex:2512.12545](https://arxiv.org/abs/2512.12545)

## Summary

TianXing-S2S is a multi-sphere coupled probabilistic deep learning model designed for global subseasonal-to-seasonal (S2S) ensemble forecasting. The model encodes diverse multi-sphere predictors into a latent space and leverages a diffusion model equipped with an optimal transport-based coupling module to capture complex atmospheric and boundary interactions. Evaluated on 45-day daily-mean forecasts, TianXing-S2S outperforms established operational systems like ECMWF S2S and FuXi-S2S while supporting stable rollout forecasts up to 180 days.

## Key Contributions

- Introduces TianXing-S2S, a multi-sphere coupled probabilistic deep learning model for global subseasonal-to-seasonal ensemble forecasting.
- Employs a diffusion model with an optimal transport-based coupling module to optimize interactions between atmospheric and multi-sphere boundary conditions.
- Outperforms ECMWF S2S and FuXi-S2S systems in 45-day daily-mean ensemble forecasts across key atmospheric variables at 1.5° x 1.5° resolution.
- Demonstrates stable rollout forecasting capability up to 180 days, improving extreme event prediction such as heat waves and anomalous precipitation.
