# A cosmic-ray database update: CRDB v4.2

**Authors**: Davud Maurin
**Date**: 2026-09-07
**Paper ID**: [openalex:2609.07630](https://arxiv.org/abs/2609.07630)

## Summary

The paper presents CRDB v4.2, a major update to the cosmic-ray database (CRDB) that has served the astroparticle physics community since 2013. This release integrates recent data and time series published over the prior three years from major experiments such as AMS-02, CALET, DAMPE, and LHAASO, alongside historical and recent ultra-high energy cosmic-ray measurements. In total, the release incorporates over 60 experiments, yielding 4,534 new data points and 131,624 time-series data points accessible via a web interface and a Python library.

## Key Contributions

- Presented CRDB v4.2, an updated cosmic-ray database incorporating peer-reviewed data from over 60 experiments and publications.
- Added 4,534 new standard data points and 131,624 time-series data points from recent observations (AMS-02, CALET, DAMPE, LHAASO) and historical ultra-high energy cosmic-ray studies.
- Provided access to updated datasets and metadata through both an enhanced web interface and a pip-installable Python library.
