# Unveiling Amplitude Distributions via the Ordinal Language of Random Walks

**Authors**: Alberto Mateos Roig, Luciano Zunino, Felipe Olivares
**Date**: 2026-07-30
**Paper ID**: [openalex:2607.28266](https://arxiv.org/abs/2607.28266)

## Summary

This paper investigates how the ordinal structure of integrated time series (random walks) can capture the amplitude distribution of underlying non-Gaussian fluctuations, overcoming the traditional view that ordinal patterns are insensitive to amplitude distributions. The authors derive analytical expressions for ordinal pattern probabilities using independent non-Gaussian increments and validate them via q-Gaussian simulations. Furthermore, they demonstrate that different centering procedures significantly affect ordinal statistics, and apply the framework to financial logarithmic returns to uncover non-Gaussian features consistent with a cubic law.

## Key Contributions

- Derives analytical expressions for ordinal pattern probabilities associated with random walks generated from independent non-Gaussian increments.
- Shows that for symmetric distributions, specific ordinal pattern probabilities depend explicitly on the shape of the increment distribution.
- Demonstrates that centering procedures during random walk construction significantly affect resulting ordinal statistics.
- Validates the proposed framework on financial time series, revealing non-Gaussian features consistent with a cubic law.
