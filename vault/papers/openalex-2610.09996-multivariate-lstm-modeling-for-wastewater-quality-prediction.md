# Multivariate LSTM Modeling for Wastewater Quality Prediction

**Authors**: Sophie Laruelle, Innocentia Bénédicta Sossou
**Date**: 2026-10-07
**Paper ID**: [openalex:2610.09996](https://arxiv.org/abs/2610.09996)

## Summary

This paper proposes a multivariate Long Short-Term Memory (LSTM) neural network to forecast wastewater quality over a 24-hour horizon using high-frequency sensor and exogenous precipitation data from a wastewater treatment plant. Evaluated across four seasonal validation subsets against persistence and SARIMA baselines, the LSTM approach demonstrates superior performance, especially on highly noisy and nonlinear water quality indicators.

## Key Contributions

- Proposed a multivariate Long Short-Term Memory (LSTM) network for 24-hour wastewater quality forecasting using high-frequency sensor data and exogenous weather variables.
- Demonstrated the superiority of the multivariate LSTM model over persistence and SARIMA models across four seasonal validation periods, particularly for noisy and nonlinear variables.
