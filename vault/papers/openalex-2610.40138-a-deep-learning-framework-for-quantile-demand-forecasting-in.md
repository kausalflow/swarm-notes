# A Deep Learning Framework for Quantile Demand Forecasting in E-commerce with Doubly Censored Data

**Authors**: Z. Ye, Jiawen Wei, Teng Song, Chen Chen, Guangrui Ma
**Date**: 2026-10-29
**Paper ID**: [openalex:2610.40138](https://arxiv.org/abs/2610.40138)

## Summary

This paper introduces a deep learning framework for quantile demand forecasting under doubly censored e-commerce data, where true demand is obscured by stock caps and promotion boosts. The authors propose a tailored evaluation metric backed by theoretical guarantees that correlates well with oracle calibration. Extensive experiments, inventory simulations, and real-world applications confirm the method's superiority over existing baselines in retail operations.

## Key Contributions

- Introduces a deep learning framework for quantile demand forecasting under doubly censored data (capped by stock and boosted by promotions) in e-commerce.
- Proposes a tailored evaluation metric supported by theoretical guarantees that correlates strongly with the oracle calibration measure.
- Demonstrates through inventory simulations and real-world applications that the estimator surpasses existing baselines in retail operations.
