# The real butterfly effect: from the pop culture to mathematics and physics

**Authors**: Victor de Jesus Valadão, Erik Aurell, G. Boffetta, Massimo Cencini, Stefano Musacchio, Angelo Vulpiani
**Date**: 2026-07-27
**Paper ID**: [openalex:2607.24715](https://arxiv.org/abs/2607.24715)

## Summary

This paper provides a systematic synthesis of the physical manifestations of the 'butterfly effect' in fully developed turbulence, connecting standard chaotic sensitivity with Eulerian and Lagrangian spontaneous stochasticity. Using the Finite Size Lyapunov Exponent (FSLE) alongside models like the Sabra shell model and Kraichnan model, the authors bridge small-scale Lyapunov dynamics with large-scale predictability limits. Ultimately, this framework clarifies the fundamental boundaries of forecasting in high-Reynolds-number fluid flows.

## Key Contributions

- Synthesizes distinct manifestations of the butterfly effect in turbulence—ranging from classical chaos to Eulerian and Lagrangian spontaneous stochasticity—within the unifying framework of the Finite Size Lyapunov Exponent (FSLE).
- Bridges the classical small-scale Lyapunov regime with large-scale predictability using the thermal noise-extended Sabra shell model.
- Illustrates Lagrangian spontaneous stochasticity using the FSLE and the Kraichnan model.
- Clarifies the physical mechanisms and fundamental boundaries governing forecasting in high-Reynolds-number turbulent flows.
