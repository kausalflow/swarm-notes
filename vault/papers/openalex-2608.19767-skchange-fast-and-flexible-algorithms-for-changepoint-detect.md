# skchange: Fast and Flexible Algorithms for Changepoint Detection

**Authors**: Martin Tveten, Johannes Voll Kolstø, Per August Jarval Moen
**Date**: 2026-08-20
**Paper ID**: [openalex:2608.19767](https://arxiv.org/abs/2608.19767)

## Summary

Skchange is an open-source Python library for detecting structural changes and anomalous segments in time series using a modular, composable framework. It implements both cost minimisation and statistical test-based search methods designed to handle high-dimensional settings efficiently. The library integrates Numba for high computational performance and adheres to scikit-learn conventions while offering data-driven penalty calibration utilities.

## Key Contributions

- Introduces skchange, an open-source Python library implementing modular and composable changepoint and anomalous segment detection algorithms for time series.
- Provides theoretically well-founded fast search methods and algorithms tailored for high-dimensional data settings where few or many features change simultaneously.
- Features built-in utilities for automatic, data-driven penalty calibration to balance false alarms against missed detections.
- Leverages Numba and scikit-learn conventions to deliver high computational performance within a unified, extensible framework.
