# Huayu-Global: Skillful real-time quasi-global precipitation retrieval

**Authors**: Zijiang Song, Shuang Yang, Yuying Li, Zilong Zhu, Xigang Sun, Ting Liu, 肖文埜, Lina Yuan, Min Liu
**Date**: 2026-10-21
**Paper ID**: [openalex:2610.29213](https://arxiv.org/abs/2610.29213)

## Summary

Huayu-Global is a deep-learning system designed to overcome the accuracy-versus-timeliness trade-off in satellite precipitation products by fusing three geostationary sensor streams from five satellites. Generating coherent quasi-global precipitation fields every thirty minutes, the framework matches the skill of delayed products while providing timely data suitable for real-time flood forecasting and disaster response. Validated across over a million independent station records, Huayu-Global demonstrates robust event detection and precipitation-amount estimation capabilities.

## Key Contributions

- Introduces Huayu-Global, a cross-constellation deep-learning system combining sensor streams from five geostationary satellites to generate quasi-global precipitation fields every thirty minutes.
- Improves event detection and precipitation-amount estimation over traditional real-time products, achieving delayed-product-level skill across more than a million independent station records.
- Provides a scalable foundation for integrating future geostationary satellite missions into hydrological forecasting and disaster response workflows.
