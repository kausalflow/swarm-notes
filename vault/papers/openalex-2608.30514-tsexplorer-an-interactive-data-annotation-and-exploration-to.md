# TSExplorer: An interactive data annotation and exploration tool for time-series data

**Authors**: Einari Vaaras, Manu Airaksinen, Okko Räsänen
**Date**: 2026-08-31
**Paper ID**: [openalex:2608.30514](https://arxiv.org/abs/2608.30514)

## Summary

The paper introduces TSExplorer, a cross-platform tool for the interactive annotation and exploration of time-series data. The software enables users to inspect high-dimensional datasets using multiple complementary 2D visualizations generated from feature representations. It supports general-purpose research workflows such as exploratory data analysis, dataset labeling, feature representation comparison, and post-hoc label refinement.

## Key Contributions

- Introduces TSExplorer, a cross-platform tool for interactive annotation and exploration of time-series data.
- Supports inspection of high-dimensional time-series datasets through multiple complementary 2D visualizations derived from high-dimensional feature representations.
- Facilitates general-purpose workflows including exploratory data analysis, dataset annotation, feature representation comparison, and post-hoc label refinement with interactive visual feedback.
