# Establishing baseline model performances for optical turbulence forecasting

**Authors**: de Sepibus, Elena Masciadri, C. Weinberger, Otarola Angel, S. Miesske, C. Veillet, S. Ragland
**Date**: 2026-10-13
**Paper ID**: [openalex:2610.18702](https://arxiv.org/abs/2610.18702)

## Summary

This paper establishes rigorous baseline performance thresholds for optical turbulence (OT) forecasting to properly evaluate numerical weather prediction and machine learning models for telescope scheduling. Using two distinct baseline models—timescale averages and temporal evolution tracking—the authors analyze multi-year datasets from the Very Large Telescope (VLT) and Large Binocular Telescope (LBT) sites. Their findings show that predictive accuracy varies significantly across sites, parameters, timescales, and approaches, establishing that optical turbulence forecast performance must be quantified relatively to these baselines rather than in absolute terms.

## Key Contributions

- Establishes rigorous baseline performance thresholds for optical turbulence (OT) forecasting using timescale average and temporal evolution models.
- Applies evaluation frameworks to multi-year astroclimatic datasets from the Very Large Telescope (VLT) and Large Binocular Telescope (LBT) sites.
- Demonstrates that predictive accuracy depends on the observing site, parameter, timescale, and approach, proving that OT forecast accuracy must be evaluated relatively to established baselines.
- Analyzes the extrapolation of reference forecast performance values to other sites based on optical turbulence statistical characteristics.
