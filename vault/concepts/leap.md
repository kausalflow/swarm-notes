# LEAP

> *Auto-generated stub. Edit this file to add more details.*

A probabilistic forecasting framework that elicits likelihood parameters separately for each evidence item and aggregates them via a deterministic model.


## Why It Matters

LEAP replaces monolithic LLM prediction with separate likelihood elicitation per evidence item combined via an explicit prior and probabilistic model.
