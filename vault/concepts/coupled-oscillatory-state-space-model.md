# Coupled Oscillatory State-Space Model

> *Auto-generated stub. Edit this file to add more details.*

A state-space model for multimodal clinical time series where second-order oscillators are coupled via an availability-gated differential equation transition operator.


## Why It Matters

Central architecture novelty replacing fixed linear transitions with availability-gated coupled oscillators to capture cross-modal presence interactions in irregular clinical time series.

## Evidence

> CAMOS, which gives each modality a bank of second-order oscillators coupled through a matrix that sits inside the differential equation and is gated by availability
