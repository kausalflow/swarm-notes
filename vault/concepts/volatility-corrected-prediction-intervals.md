# Volatility-Corrected Prediction Intervals

> *Auto-generated stub. Edit this file to add more details.*

A post-hoc calibration procedure using GARCH modeling on forecast residuals to produce locally adaptive prediction intervals for time-series forecasters.


## Why It Matters

Introduces a novel post-hoc calibration framework using GARCH modeling on standardized residuals to correct for local scale miscalibration in time-series foundation models.

## Evidence

> We then propose Volatility-Corrected Prediction Intervals (VCPI), a post-hoc calibration procedure that uses the base forecaster's predictive scale as a baseline, models the volatility of standardized forecast residuals with a Generalized Autoregressive Conditional Heteroskedasticity (GARCH) model, and applies a multiplicative correction to produce locally adaptive prediction intervals.
