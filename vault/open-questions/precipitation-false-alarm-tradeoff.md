title: Balancing Event Detection and False Alarms
---

**Background:** Hourly precipitation forecasting involves severe distributional imbalance and degradation of event skill at longer forecast lead times, which machine learning models often address by trading off false alarms against missed high-intensity events.

**Question / Future Work:** Future work should focus on improving the trade-off between detecting high-intensity precipitation events and controlling false alarm rates (FAR) in data-driven and physics-guided spatiotemporal forecasting frameworks.

**Why It Matters:** Balancing high-intensity event detection with false alarm rates is a persistent bottleneck in imbalanced spatiotemporal classification and regression tasks.

**Evidence:** They also highlight an important trade-off: increased sensitivity to moderate and heavy precipitation can be accompanied by higher false alarm rates.
