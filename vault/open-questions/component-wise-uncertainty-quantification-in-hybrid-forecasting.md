title: Component-Wise Uncertainty Quantification
---

**Background:** Operational flood forecasting relies on the integration of physical simulations, expert knowledge, and data-driven methods, but quantifying and isolating uncertainty across all workflow components remains challenging.

**Question / Future Work:** Design comprehensive and idealized experimental frameworks to thoroughly quantify and isolate the uncertainty stemming from each individual component within the forecasting workflow, including meteorological forcing variables, hydrological model structures, parameter calibration, and language model reasoning.

**Why It Matters:** Essential for building trustworthy and robust AI-assisted operational forecasting systems where error sources must be transparently traced and bounded.

**Evidence:** Future work could design an idealized experiment to quantify the uncertainty from each component in HydroAgent. This can be done by using an ensemble framework of meteorological forcing variables, and different hydrological models.
