title: End-to-End Text Composition
---

**Background:** Multimodal time series forecasting models leverage textual and visual descriptions to improve prediction accuracy, but existing approaches rely on hand-crafted templates.

**Question / Future Work:** Developing automated, end-to-end text composition methods—potentially utilizing small language models distilled from domain experts—to generate and refine time series descriptions for improved domain adaptability.

**Why It Matters:** Automating text generation removes the dependency on manual prompt engineering and allows dynamic adaptation to diverse temporal domains.

**Evidence:** First, the current text generation relies on hand-crafted templates; learning to compose descriptions end-to-end, potentially via a small language model distilled from domain experts, could further improve text quality and domain adaptability.
